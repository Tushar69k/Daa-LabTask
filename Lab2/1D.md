# Program 1 — 1D Array Operations (`array_1d_ops.py`)

## Aim
Let the user work with a 1D array (a Python list) through a menu: insert at
an index, delete at an index, linear search, and rotate left/right by `k`
positions — printing the array after every operation.

## Logic
Each operation is its own function so it can be tested and reasoned about
independently of the menu loop. `insert_at_index` / `delete_at_index` do
bounds checking before touching the list (valid insert indices go up to
`len(arr)` inclusive since you can insert at the end; valid delete indices
stop one short of that). Rotation is done by slicing rather than
element-by-element shifting — `arr[k:] + arr[:k]` for a left rotation — and
`k` is first reduced with `k % n` so a rotation amount larger than the
array length still behaves correctly instead of erroring or doing extra
wasted rotations.

## Functions
- `insert_at_index(arr, index, value)` — validates `0 <= index <= len(arr)`
- `delete_at_index(arr, index)` — validates `0 <= index < len(arr)`, and rejects deleting from an empty array
- `linear_search(arr, value)` — scans left to right, returns index or `-1`
- `rotate_left(arr, k)` / `rotate_right(arr, k)` — slice-based rotation, `k` normalized with `% n`
- `menu()` — the interactive loop that ties everything together and prints the array after each op

## Sample Input / Output
Reproducing the worksheet's Section B Q1 trace:

```
Array: []
Insert 10 at 0 -> Array: [10]
Insert 20 at 1 -> Array: [10, 20]
Insert 30 at 2 -> Array: [10, 20, 30]
Insert 40 at 3 -> Array: [10, 20, 30, 40]
Insert 50 at 4 -> Array: [10, 20, 30, 40, 50]
Insert 25 at 2 -> Array: [10, 20, 25, 30, 40, 50]
Delete index 0 -> Array: [20, 25, 30, 40, 50]
Rotate left 2  -> Array: [30, 40, 50, 20, 25]
```

Linear search: `linear_search([5, 12, 8, 19, 3, 27], 19)` → `3` (matches the Section B Q2 trace).

**Boundary cases tested:**
- `insert_at_index(arr, 99, 1)` on a 5-element array → `IndexError: Insert index 99 out of bounds for array of size 5`
- `delete_at_index([], 0)` on an empty array → `IndexError: Cannot delete from an empty array`
